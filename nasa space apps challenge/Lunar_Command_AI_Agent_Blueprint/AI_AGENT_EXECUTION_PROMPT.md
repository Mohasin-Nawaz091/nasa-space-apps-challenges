# AI AGENT --- LUNAR COMMAND EXECUTION PROMPT

You are assigned to implement the complete Lunar Command project in the
currently opened repository.

## Required first action

Read `LUNAR_COMMAND_MASTER_PLAN.md` from beginning to end before
changing any files.

That document is the source of truth for the project vision, technology
stack, game mechanics, architecture, phased implementation, acceptance
criteria, and final definition of done.

## Execution instructions

1.  Inspect the existing repository and current project state.
2.  Start with Phase 0 of the master plan.
3.  Execute every phase sequentially, from Phase 0 through Phase 15.
4.  Implement the actual application. Do not respond with plans or code
    snippets in place of implementation.
5.  Do not stop after creating a landing page, HUD mockup, or initial 3D
    scene.
6.  Do not ask the user for approval between phases. Make sensible
    technical decisions independently.
7.  Preserve existing working files and dependencies. Inspect before
    overwriting.
8.  Keep rendering, simulation, UI, NASA data, and mission configuration
    separated.
9.  Make every visible interactive control functional.
10. Maintain `docs/IMPLEMENTATION_PROGRESS.md` and update it after every
    phase.
11. Test each phase against the acceptance criteria before marking it
    complete.
12. Fix errors before proceeding. Do not knowingly carry critical errors
    into later phases.
13. Use real, properly licensed assets or create original assets. Record
    attribution.
14. Keep NASA data scientifically honest. Never present fictional game
    values as NASA measurements.
15. If an external API, asset, credential, or deployment permission is
    unavailable, implement a documented fallback and continue all
    independent work.
16. Do not claim that deployment, testing, or a feature succeeded unless
    you actually verified it.

## Required progress report after each phase

Report briefly: - Phase number and name. - Features implemented. - Files
created or modified. - Tests executed and their results. - Known issues
or blockers. - Next phase.

Then continue automatically to the next phase.

## Final delivery

The task is complete only when the master plan's final definition of
done has been met.

At the end: - Run the production build. - Run the available lint and
test commands. - Verify the main gameplay flow in the browser where
browser testing is available. - Update the README and all required
project documentation. - Provide a concise final report listing
implemented features, verification results, deployment URL if actually
deployed, and any remaining limitations.
